Visualização
Visualização é uma área dedicada à geração de imagens
que auxiliam seus usuários na compreensão de dados e
processos.
Uma das principais características da área é a
interdisciplinaridade, já que áreas tradicionais das ciências,

incitam o desenvolvimento de técnicas de visualização.

## Página 18

Visualização pragmática
Três critérios mínimos que qualquer visualização deve
respeitar para ser considerada pragmática

1. Basear-se em dados (não-visuais)
2. Produzir uma imagem
3. O resultado deve ser legível e reconhecível
   18
   Robert Kosara, Visualization Criticism – The Missing Link Between Information Visualization and Art, Proceedings of the
   11th International Conference on Information Visualisation (IV), pp. 631–636, 2007.

## Página 19

Visualização pragmática

1. Basear-se em dados (não-visuais)
   Propósito de uma visualização: comunicação de dados
   Dados devem vir de alguma forma abstrata ou ao
   menos não imediatamente visível (por exemplo, o
   interior do corpo humano).
   Descartam-se fotografia e processamento de imagem.
   Visualização transforma do invisível para o visível.
   19

## Página 20

Visualização pragmática 2. Produzir uma imagem
Devia ser óbvio, mas nem sempre tão claro.
O visual deve ser o modo primário de comunicação
Outras modalidades devem prover apenas informações
adicionais
Se a imagem é apenas uma pequena parte do processo,
então não é visualização.
20

## Página 21

Visualização pragmática
O resultado deve ser legível e reconhecível.
Critério mais importante.
A visualização deve prover um aprendizado sobre os dados
Qualquer transformação de dados não-triviais em imagem
vai deixar alguma informação de fora, mas devem
permanecer aspectos relevantes dos dados que possam ser
lidos
A visualização também deve ser reconhecível como tal e
não parecer outra coisa.
21

## Página 38

Visualização como ferramenta de
descoberta

ausência) de padrões, relacionamentos, e características
físicas (por exemplo, outliers) através de um display
visual.
Visualização está fortemente relacionada ao processo de
descoberta.
